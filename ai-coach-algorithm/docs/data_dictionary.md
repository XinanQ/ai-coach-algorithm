# 话术资料字段说明

## standard_scripts.csv

- 话术ID：标准话术唯一编号
- 场景ID：关联训练场景
- 客户问题：客户可能提出的问题
- 标准回答：用于评分和反馈参考
- 必须覆盖点：完整度评分依据
- 推荐关键词：关键词命中评分依据
- 薄弱标签：未覆盖时可输出的能力短板

## compliance_terms.csv

- 禁语/风险表达：需要检测的金融风险表达
- 风险等级：高/中/低
- 替代表达：反馈时推荐的更合规表达
- 扣分建议：合规评分规则

## scoring_rules.csv

- 评分维度：关联五大评分维度
- 评分点：规则说明
- 命中方式：关键词匹配、必答点检查、禁语检测等
- 对应薄弱标签：未命中时输出的能力标签
